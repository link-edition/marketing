# Marketing Audit App

🚀 Professional Marketing & Budget Audit Tool built with Flask + JavaScript

## Features

- ✨ Modern glassmorphism UI with particles animation
- 🎊 Confetti celebration on results
- ⌨️ Typing effect for questions
- 🎯 Smart business recommendations
- 💰 Budget calculation with penalty system
- 📊 Funnel breakdown visualization
- 📱 Fully responsive design

## Tech Stack

- **Backend:** Python Flask
- **Frontend:** Vanilla JavaScript, CSS3
- **Fonts:** Google Fonts (Outfit)
- **Icons:** Font Awesome 6

## Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/marketing-audit-app.git
cd marketing-audit-app

# Install dependencies
pip install flask

# Run the app
python app.py
```

## Usage

1. Open `http://localhost:5000` in your browser
2. Answer 9 questions about your business
3. Get personalized recommendations and budget calculations
